# Limare Web UI (Demo)

Interactive web recreation demo of Limare for macOS.

## Quick Start (Local Preview)

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# Or start for LAN preview (phones/tablets on same Wi-Fi)
npm run dev -- --host

# 3. Production build & test preview
npm run build
npm run preview
```

> **Note**: Do not double click `index.html` directly from Finder (`file://`), as modern ES modules and assets require an HTTP server.
