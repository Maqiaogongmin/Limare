# Support

Limare 0.1.0 targets **Apple Silicon and macOS 15.0+**.

Use GitHub Issues for public bug reports once the clean source repository is
published. Include your Limare version, macOS version, expected behavior,
actual behavior, and minimal reproduction steps. Sanitize logs and screenshots
before sharing them. Do not include keys, tokens, private conversations, or
personal identifiers.

For private installation, privacy, or security reports, email
**mail@limare.app**. The address can receive reports but cannot currently send
replies. Public, non-sensitive issue discussions provide a follow-up channel.
Security reports must remain private; see [SECURITY.md](SECURITY.md).

Read the [privacy policy](https://limare.app/privacy/) before enabling model,
tool, browser, voice, Computer Use, or Remote Access features.

Updates are checked only when you choose **Limare > Check for Updates…**.
There is no background update notification. Follow GitHub Releases for version
and security announcements.

Public downloads remain closed until the source, signed/notarized DMG,
anonymous download checks, and update feed have passed release validation.
